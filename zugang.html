Erste Schritte

Zugang bekommen

Für jede Gruppe, die ILS Eggingen nutzen möchte – z. B. eine Jugendfeuerwehr oder eine Veranstaltung – wird eine eigene, unabhängige Übungsleitstelle eingerichtet. Es gibt keine Selbstregistrierung, der Zugang wird auf Anfrage angelegt.

Kurzfassung

E-Mail an system@ils.ulm-eggingen.de mit Name der Gruppe/Jugendfeuerwehr und Ansprechperson – ihr bekommt eine eigene Leitstelle mit einem ersten Admin-Zugang zugeschickt.

So läufts ab

  1. Anfrage per E-Mail stellen

    Schreib eine E-Mail an system@ils.ulm-eggingen.de. Am schnellsten geht es mit folgenden Angaben:

    • Name der Jugendfeuerwehr / Gruppe / Veranstaltung
    • Ansprechperson (Vor- und Nachname)
    • Kurz, wofür die Leitstelle genutzt werden soll (z. B. Gruppenstunde, Übung, Tag der offenen Tür) und ungefährer Zeitraum

  2. Eigene Leitstelle wird eingerichtet

    Für eure Gruppe wird eine komplett eigene, von anderen Gruppen unabhängige Leitstellen-Instanz angelegt – inklusive einem ersten Admin-Konto.

  3. Zugangsdaten erhalten

    Ihr bekommt den Leitstellen-Namen sowie Benutzername und ein Startpasswort für das Admin-Konto zugeschickt. Bewahrt das sicher auf.

  4. Weitere Benutzer selbst anlegen

    Mit dem Admin-Konto könnt ihr danach selbstständig weitere Benutzerkonten für eure Gruppe anlegen (z. B. für andere Betreuer oder die Jugendlichen) – siehe Verwaltung (Admin) und Rollen & Rechte.

Nur für angefragte Gruppen

Jede Leitstelle ist von den anderen getrennt – eure Gruppe sieht nur eure eigenen Daten. Gebt eure Zugangsdaten trotzdem nicht an Dritte weiter.
